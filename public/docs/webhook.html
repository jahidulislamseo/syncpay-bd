Webhook API

Webhook API

Real-time payment events আপনার server-এ পাঠান। কোনো polling লাগবে না — SMS পাওয়ার সাথে সাথে আপনার URL-এ HTTP POST যাবে।

Webhook ব্যবহার করলে payment detect হওয়ার 2-5 সেকেন্ডের মধ্যে আপনার system নোটিফাই হয়।

Webhook কীভাবে কাজ করে

আমাদের Android agent SMS পেলে PayFlow server-কে জানায়। Server তখন আপনার registered webhook URL-এ HTTP POST পাঠায়। আপনার server 200 OK দিলে delivery confirmed।

Webhook Setup

1

Dashboard থেকে Webhook URL register করুন

Settings → Webhooks → Add Endpoint-এ আপনার server URL দিন।

2

Secret Key সংগ্রহ করুন

Signature verify করতে এই secret দরকার হবে।

3

HTTPS endpoint তৈরি করুন

আপনার server-এ একটি POST endpoint বানান। Webhook শুধু HTTPS-এ পাঠানো হয়।

4

Signature verify করুন ও 200 দিন

Request valid হলে 200 OK response দিন। অন্যথায় retry হবে।

Events

নিচের events-এর জন্য webhook পাঠানো হয়:

Eventকখন পাঠানো হয়
payment.receivedনতুন payment SMS detect হলে
payment.verifiedTransaction verify হলে
payment.failedVerification fail হলে
payment.expiredInvoice expire হলে

Signature Verification

প্রতিটি webhook request-এ X-PayFlow-Signature header থাকে। Request body-র HMAC-SHA256 hash verify করুন।

// PHP — Signature verify
$payload   = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_PAYFLOW_SIGNATURE'];
$expected  = 'sha256=' . hash_hmac('sha256', $payload, $webhookSecret);

if (!hash_equals($expected, $signature)) {
  http_response_code(401);
  exit('Invalid signature');
}

// Valid — process করুন
$data = json_decode($payload, true);
http_response_code(200);
Signature verify না করলে যেকেউ fake webhook পাঠাতে পারে। সবসময় verify করুন।

Retry Policy

আপনার server 200 না দিলে বা timeout হলে আমরা retry করি:

AttemptDelay
1st retry30 seconds
2nd retry5 minutes
3rd retry30 minutes
4th retry2 hours
Final24 hours — তারপর abandon
Webhook handler idempotent রাখুন — একই event একাধিকবার পেলেও duplicate order না হয়।
